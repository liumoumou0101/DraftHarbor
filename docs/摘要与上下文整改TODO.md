## 实施原则

1. 摘要是可编辑的项目数据，任何自动生成都不应静默覆盖用户内容。
2. 上下文宁可缺少过期摘要，也不应注入可能错误的剧情信息。
3. 单次模型请求必须有可解释的字符或 Token 预算。
4. 每个修复都要覆盖成功、失败和重新打开项目后的持久化行为。
