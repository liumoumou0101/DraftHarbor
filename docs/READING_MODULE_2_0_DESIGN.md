## 1. 决策摘要

Reader 2.0 不再被定义为“写作区的正文预览页”，而是一款可以独立成立的本地桌面小说阅读器。它首先必须完整、舒适、稳定地完成长期阅读；在此基础上，才增加稿湾特有的来源定位、选区转交、写作定位和半自动工作流输入能力。

本轮不推翻 F-10 已完成的 Reader Document v2、Reader Store、稳定 Locator、分页核心和 Transfer Envelope。它们是可靠的数据地基。Reader 2.0 主要重做：

- 产品定位、书库首页和信息架构。
- 文件导入、项目入口与新版 Reader Store 的统一闭环。
- 专注阅读舞台、完整主题、纸张和排版体验。
- 字体目录与未来用户字体安装能力。
- 页面布局、翻页行为、阅读导航、批注和状态栏。
- 视觉验收标准，从“无溢出、对比度合格”提升到“可作为专业阅读器长期使用”。

旧 F-10 文档继续作为历史架构与发布记录。本文件覆盖它的产品体验、视觉层和后续功能范围；两者冲突时，Reader 2.0 的产品决定优先，但不得削弱 F-10 的数据安全、版本、定位、恢复和转交边界。

## 2. 产品定位

### 2.1 一句话定义

Reader 2.0 是稿湾内置的专业本地小说阅读器：它让用户舒适地管理和阅读项目正文或外部小说，并可把明确选择的内容安全转到写作、资料库或半自动工作流。

### 2.2 独立成立标准

即使关闭写作、资料库、讨论和工作流模块，Reader 2.0 仍必须具备一款合格桌面小说阅读器应有的完整体验：

- 真正的书库与继续阅读。
- 稳定的流式、单页、双页和自动分页。
- 完整的字体、字号、字距、行距、段距、版心和页边距设置。
- 日间、纸张、护眼、夜间和自定义阅读主题。
- 纸张材质、页面阴影、双页书脊和背景层级。
- 多种翻页输入和动效。
- 目录、搜索、进度、书签、高亮、批注和位置历史。
- 全局设置、单书设置和可保存阅读方案。
- 长篇性能、位置恢复、缩放和无障碍。

### 2.3 核心模块关系

| 模块 | 首要职责 | Reader 与其关系 |
| --- | --- | --- |
| 写作 | 创建、编辑并确认项目正文 | Reader 只读项目投影，可从阅读位置返回来源场景 |
| 半自动工作流 | 版本化生成、分析、重写与写回 | Reader 冻结用户选择并创建可追溯输入 |
| Reader 2.0 | 书库管理、沉浸阅读、导航、批注与选区 | 首先是阅读器，其次才是跨模块来源入口 |
| 资料库 | 管理正式设定事实 | Reader 可提供明确范围的资料提取来源 |

Reader 不拥有模型、Prompt、资料卡审核或工作流运行。普通阅读时，不显示任何 AI 或跨模块操作；只有进入选择模式后，才提供转交动作。

## 3. 产品原则

1. **阅读优先。** 正文、纸张和阅读节奏是视觉中心，应用导航与工具控件不得长期抢占空间。
2. **完整阅读器优先于稿湾联动。** 转交能力不能掩盖书库、排版、导航等基础体验缺失。
3. **渐进披露。** 高频设置一键可达，低频参数进入高级设置；普通阅读不展示选择和转交控件。
4. **位置永远稳定。** 任何字体、字号、窗口、布局、主题或分页变化都先捕获 Locator，再重排恢复。
5. **本地优先。** 正文、字体、纸张素材、批注和阅读状态均默认本地保存，不依赖远程资源。
6. **主题是完整环境。** 主题必须覆盖阅读舞台、页面、悬浮控件和抽屉，而不是只改变正文矩形。
7. **视觉品质可验收。** 不再只检查“没坏”；必须对信息层级、沉浸度、纸张质感、排版节奏和交互反馈做人工视觉验收。
8. **扩展能力从首日建模。** 首期可以只注册一种字体，但偏好、缓存、服务和 UI 不能把字体写死。

## 4. 目标用户与主要任务

### 4.1 目标用户

- 在稿湾中持续创作并需要通读项目成稿的作者。
- 阅读本地 TXT/Markdown 小说并做书签、批注或摘录的用户。
- 需要从阅读态选择内容，再进入写作或半自动工作流处理的用户。
- 对字体、纸张、分页和翻页手感有明确偏好的长期阅读者。

### 4.2 核心任务

1. 从书库继续上次阅读。
2. 导入一本本地小说，确认章节后加入书库。
3. 打开当前项目的只读成稿视图，按章或按场景阅读。
4. 调整字体、纸张、页面宽度和翻页行为，并保存为方案。
5. 通过目录、搜索、进度、书签或历史位置跳转。
6. 高亮或批注重要段落。
7. 选择选区、场景、章节或全文，转到写作或半自动工作流。

## 5. 范围与分层

### 5.1 Reader 2.0 必须覆盖

- 项目正文、TXT、Markdown 和粘贴文本。
- 书库、书籍详情、导入向导和最近阅读。
- 连续、单页、双页、自动布局。
- 完整排版、主题、纸张和翻页偏好。
- 目录、搜索、进度、书签、高亮、批注、位置历史。
- 全局、单书和用户阅读方案。
- 键盘、鼠标、触控区与减少动态效果。
- 选区到写作、资料库和工作流的安全转交。
- 字体目录和应用内用户字体扩展接口。

### 5.2 可在后续小版本开启，但本版必须预留接口

- EPUB 导入。
- TTS 朗读、定时停止和朗读位置同步。
- 阅读统计与每日目标。
- 云同步和跨设备进度。
- 更多纸张材质包和主题包。
- 仿真卷页动画。
- 用户字体文件导入与管理 UI。

这些能力可以分期实现，但数据结构、扩展点和布局协议不得再次大改。

### 5.3 暂不支持

- 修改外部源文件。
- PDF 排版重建、扫描件 OCR 或复杂图文书籍。
- Reader 内直接生成或覆盖正文。
- 未经确认自动把选区发送给模型或目标模块。
- 远程字体、远程纸张素材或联网主题市场。

## 6. 信息架构

Reader 2.0 包含六个正式产品空间：

```text
Reader
├─ 阅读书库
│  ├─ 继续阅读
│  ├─ 项目作品
│  ├─ 本地书籍
│  ├─ 收藏与书架
│  └─ 导入
├─ 书籍详情
│  ├─ 元数据与来源
│  ├─ 章节与版本
│  └─ 阅读状态
├─ 专注阅读
│  ├─ 阅读舞台
│  ├─ 导航中心
│  ├─ 快捷外观
│  └─ 外观工作室
├─ 批注层
│  ├─ 高亮
│  ├─ 笔记
│  └─ 位置历史
├─ 选择与转交
│  ├─ 选区/场景/章节/全文
│  └─ 写作/资料库/工作流
└─ 导入向导
   ├─ 文件与编码
   ├─ 章节识别
   ├─ 校正预览
   └─ 确认入库
```

### 6.1 状态模型

| 状态 | 主体 | 常驻操作 | 不应出现 |
| --- | --- | --- | --- |
| `library` | 书架、封面、继续阅读 | 打开、导入、筛选、管理 | 正文进度条、翻页按钮 |
| `book-detail` | 书籍与来源信息 | 开始/继续、目录、版本 | 写作和工作流动作 |
| `reading` | 正文或纸张页面 | 轻量章节和进度 HUD | 常驻 AI、导入表单 |
| `appearance` | 正文实时预览 + 设置面板 | 预设、微调、保存方案 | 遮住整个正文的强遮罩 |
| `annotation` | 文本选择和批注工具 | 高亮、笔记、书签 | 跨模块目标默认展开 |
| `transfer` | 已确认范围与来源摘要 | 去写作、资料库、工作流 | 字体和纸张设置 |
| `import` | 导入预览与章节结构 | 编码、拆分、合并、确认 | 直接进入兼容 localStorage |

## 7. 阅读书库

### 7.1 书库首页

默认进入书库而不是空阅读器。首页至少包含：

- 继续阅读：最近一本书的封面、当前章节、进度和“继续阅读”。
- 最近阅读：横向或网格书籍列表。
- 项目作品：从 Project Store 派生，只读展示项目标题、章节数、字数和最近修改。
- 本地书籍：Reader Store 中的 TXT、Markdown 和粘贴文档。
- 自定义书架：收藏、稍后阅读、已读、用户分组。
- 导入入口：明确进入新版导入向导。

书库空状态只显示导入和项目作品入口，不渲染无意义的阅读进度、章节导航或键盘提示。

### 7.2 书籍卡片

卡片展示：

- 封面或稳定生成的本地占位封面。
- 标题、作者或来源类型。
- 当前章节与全书进度。
- 最近阅读时间。
- 项目/本地/粘贴来源徽标。
- 收藏、更多和继续阅读动作。

占位封面不能依赖远程服务。正式视觉实现应使用设计资产或本地生成资源，不使用临时 CSS 图形冒充最终封面素材。

### 7.3 书籍详情

书籍详情负责管理，不与阅读舞台混合：

- 标题、作者、简介、封面、来源、格式、字数和章节数。
- 最近位置、总阅读时间和阅读状态。
- 目录预览与版本列表。
- 本地文档重新导入、更新元数据、移出书架或安全删除。
- 项目作品显示项目版本与最近修改，不复制正文。

## 8. 导入向导

当前可见 `input[data-reader-file]` 不能继续调用旧 `localStorage` 兼容导入。所有新导入统一经过现有 Reader Store 草稿 API：

1. 选择文件或粘贴文本。
2. 检测格式、编码、乱码风险和章节结构。
3. 显示章节列表、样章预览和异常提示。
4. 支持修改标题、拆分章节、合并章节和编码重试。
5. 用户确认后写入 Reader Store。
6. 重新读取正式文档与 Reader State。
7. 成功后进入书籍详情或开始阅读。

旧 `draftharbor:desktop:reader` 只用于迁移，不能再成为新文档的主路径。迁移成功后才清除旧键；失败保持可重试。

## 9. 专注阅读舞台

### 9.1 默认结构

阅读时正文是唯一视觉主体。建议结构：

- 顶部 HUD：书名、章节名、返回书库、目录、外观；默认弱化或自动隐藏。
- 中央阅读舞台：流式正文或一/两张纸张页面。
- 左右翻页热区：仅在分页布局激活，悬停或键盘聚焦时可见。
- 底部状态栏：页码/章节/全书进度/剩余时间，由用户选择显示项。
- 浮动选择工具条：只有文本选择存在时出现。

进入阅读后可以自动收起稿湾全局左导航和应用标题栏。鼠标移动到边缘、按 `Esc`、`Alt` 或设置的快捷键时恢复。用户也可关闭自动隐藏。

### 9.2 控件可见性

| 状态 | 顶部 HUD | 章节栏 | 底部状态 | 全局导航 |
| --- | --- | --- | --- | --- |
| 初次进入 | 显示 | 合并到 HUD | 显示 | 可见后自动收起 |
| 稳定阅读 | 自动隐藏 | 不单独占行 | 细线或隐藏 | 收起 |
| 鼠标/键盘激活 | 浮现 | 作为 HUD 信息 | 浮现 | 边缘触发 |
| 选择文本 | 显示必要动作 | 不变 | 保持 | 不自动展开 |
| 打开设置 | 显示关闭和方案 | 不变 | 可隐藏 | 保持收起 |

不得再同时常驻应用栏、Reader 顶栏、章节栏和底栏四层 chrome。

## 10. 排版系统

### 10.1 排版参数

| 参数 | 建议范围 | 默认 | 是否影响分页 |
| --- | --- | --- | --- |
| 字号 | 14–36 px | 18 px | 是 |
| 字重 | 可用字体支持的 300–700 | 400 | 是 |
| 行距 | 1.35–2.40 | 1.80 | 是 |
| 字距 | -0.04–0.18 em | 0 | 是 |
| 段距 | 0–2.0 em | 1.05 em | 是 |
| 首行缩进 | 0–4 em | 2 em | 是 |
| 版心宽度 | 520–1100 px | 760 px | 是 |
| 页面边距 | 16–120 px | 48 px | 是 |
| 双页栏距/书脊 | 16–80 px | 36 px | 是 |
| 文本对齐 | 自然/两端 | 自然 | 是 |
| 标点挤压 | 关闭/基础 | 基础 | 是 |

所有滑杆必须显示实时数值、默认点和重置动作。高频设置提供离散增减按钮，不能强迫用户精细拖动。

### 10.2 中文小说排版

- 标题、场景标题和正文块使用不同但克制的层级。
- 首行缩进不应用于标题、场景标题、代码或显式空行后的特殊块。
- 两端对齐必须防止极端字距；不足一行保持自然对齐。
- 分页不得产生不可达正文、重复字符或丢字。
- 尽量避免只有一行留在上一页或下一页；无法满足时优先保证内容和 Locator 正确。
- 中英文、数字、破折号、省略号、引号和 emoji 保持稳定切片。

## 11. 字体系统与未来安装能力

### 11.1 首期策略

开发首期可以只注册一种可靠的内置/系统默认字体，以控制视觉变量和分页风险。但从第一阶段开始，设置、数据和布局缓存必须引用稳定 `fontId`，不得直接写死 `font-family` 字符串。

### 11.2 字体目录模型

建议新增 `ReaderFontCatalogEntryV1`：

```text
fontId
displayName
source: builtin | system | user
familyNames[]
fallbackStack[]
weights[]
styles[]
fileRefs[]
status: available | missing | loading | failed | unsupported
licenseNote?
addedAt?
updatedAt?
```

用户偏好只保存 `fontId`。字体文件位置由 Font Store/Service 解析，不把任意绝对路径写进 Reader State、项目或路由。

### 11.3 字体提供者接口

布局层只依赖统一接口：

```text
listFonts()
getFont(fontId)
probeFont(fontId)
loadFont(fontId)
registerUserFont(file)
removeUserFont(fontId)
resolveFontStack(fontId)
```

首期可只实现 `builtin` 提供者并返回一个条目；后续增加 `system` 和 `user` 提供者时，不修改偏好 schema、分页入口或设置组件的数据契约。

### 11.4 用户字体安装路线

后续支持应用内字体，不强制修改操作系统字体：

- 接受经过校验的 TTF、OTF、WOFF2。
- 复制到 `DraftHarbor Library/reader-fonts/<fontId>/`。
- 存储轻量元数据、摘要、字体家族、字重和样式。
- 使用本地 `FontFace` 注册，不从远程 URL 加载。
- 检查文件大小、格式、重复摘要和加载失败。
- 删除字体前检查阅读方案引用；删除后方案保留 `fontId` 并显示“字体缺失”，自动使用回退栈。
- 字体加载或回退变化时捕获 Locator、失效分页缓存、重排并恢复同一位置。

如果未来支持系统字体枚举，只保存稳定标识和可验证名称，不把系统绝对路径暴露给普通前端。

### 11.5 字体选择 UI

- 字体列表显示中文样张“山海有信，长夜将明”与英文数字样张。
- 区分内置、系统和用户字体。
- 显示可用、缺失或加载失败状态。
- 支持收藏和最近使用。
- 字体切换在当前页实时预览，确认后保存到全局、当前书籍或阅读方案。

## 12. 主题、背景与纸张系统

### 12.1 分层模型

一个阅读主题不是单一颜色，而是以下组合：

```text
ReaderTheme
  environment      # 舞台与外围
  page              # 纸张底色/纹理/边缘
  text              # 正文、标题、弱文本
  controls          # HUD、按钮、焦点和选区
  material          # 纸张纹理资产及强度
  effects           # 阴影、书脊、晕影、亮度
```

### 12.2 内置主题

首个完整版本至少提供：

- 明亮白纸。
- 米白书籍纸。
- 暖黄轻型纸。
- 护眼低饱和绿。
- 深色墨灰。
- OLED 纯黑。

纸张材质可以包含书籍纸、轻型纸、旧书纸、宣纸等本地纹理。正式纹理必须使用真实本地素材或生成资产，不用临时 CSS 噪点冒充最终设计。

### 12.3 可调参数

- 环境背景色。
- 纸张底色与正文颜色。
- 强调色、选区色和链接/标记色。
- 纹理类型、缩放、透明度和颗粒强度。
- 页面阴影、边缘、圆角和双页书脊强度。
- 亮度、色温、对比度和晕影。

每个主题必须分别验证正文、次级文字、控件、焦点和选区对比度。减少动态和高对比度模式可以覆盖装饰效果，但不改变正文内容。

## 13. 布局、分页与翻页

### 13.1 布局模式

- 连续滚动：垂直阅读，虚拟化渲染。
- 单页：每次一张完整页面。
- 双页：固定左到右，奇数尾页单页收尾。
- 自动：按可用宽度、高度、缩放和最小页面尺寸选择单/双页；空间不足时降为连续模式。

### 13.2 翻页输入

- 点击左右热区。
- 鼠标滚轮。
- 方向键、PageUp/PageDown、Space。
- 触控点击或滑动。
- 底部上一页/下一页。
- 进度滑杆或页码跳转。

存在文本选择、批注编辑或打开对话框时，不得误触翻页。

### 13.3 翻页效果

按能力逐步提供：

- 无动画。
- 淡入。
- 平移。
- 覆盖。
- 仿真翻页。

动画只影响呈现，不创建第二套正文或位置。减少动态效果必须降级为无动画。仿真翻页在性能和可访问性未通过前保持实验状态，但接口应允许后续新增 `transitionAdapter`。

### 13.4 自动翻页

后续启用自动翻页：

- 按页停留时间或阅读速度设置。
- 暂停、继续、临时加速和定时停止。
- 窗口失焦、打开面板、选择文本或 TTS 启动时自动暂停。

## 14. 导航、进度与阅读历史

### 14.1 导航中心

左侧或悬浮导航中心包含：

- 目录。
- 搜索。
- 书签。
- 高亮与批注。
- 阅读历史。

这些功能共享书籍上下文，但不再用四个等权标签挤在窄抽屉顶部。导航中心应保留上次打开的分区，并为长目录提供搜索、折叠和当前章定位。

### 14.2 进度

进度仍按内容权重与 Locator 计算，不保存永久页码。可显示：

- 当前页/总页数（当前排版派生）。
- 当前章/总章节。
- 章节百分比。
- 全书百分比。
- 已读字符数。
- 预计本章/全书剩余时间。

用户可决定底部状态栏显示哪些字段。空书库或未打开书籍时不显示进度。

### 14.3 位置历史

维护轻量前进/后退栈：

- 目录跳转前的位置。
- 搜索结果跳转前的位置。
- 书签或批注跳转前的位置。
- 从写作/工作流返回后的来源位置。

历史只保存 Locator 和摘要，不保存全文。

## 15. 书签、高亮与批注

### 15.1 书签

保留现有稳定 Locator 书签，并增加：

- 用户标题和备注。
- 颜色或分类。
- 创建时间和最近访问时间。
- exact/approximate/unresolved 恢复状态。

### 15.2 高亮

支持多种可访问颜色、下划线和边线样式。高亮保存 Reader Range，不在正文中插入标记。跨修订恢复沿用 Locator 解析。

### 15.3 批注

批注绑定一个范围或当前位置，包含：

- `annotationId`。
- 颜色/类型。
- Reader Range。
- 用户笔记。
- 创建与更新时间。
- 恢复精度。

批注进入 Reader State 或独立 Annotation Store，不写入项目正文。项目来源可提供“在写作中定位”，但不自动修改场景。

## 16. 外观工作室

### 16.1 两层结构

**快捷外观条**只放高频操作：

- 主题预设。
- 字号减/数值/加。
- 字体。
- 连续/单页/双页。
- 更多设置。

**外观工作室**分区：

1. 方案：内置和用户方案。
2. 纸张：主题、材质、纹理、环境。
3. 字体：字体目录、字号、字重和样张。
4. 排版：行距、字距、段距、缩进、版心和页边距。
5. 页面：布局、书脊、阴影和状态栏。
6. 翻页：输入、动画、速度、减少动态。

### 16.2 实时预览

设置面板不使用强遮罩完全压暗正文。用户调整时保持当前页可见，所有影响分页的参数先捕获 Locator，重排后恢复。每项修改可撤销、重置或保存为：

- 所有书籍默认。
- 当前书籍覆盖。
- 新的阅读方案。

## 17. 选择与稿湾转交

### 17.1 进入方式

普通阅读不显示“去写作”或“去工作流”按钮。用户通过以下方式进入选择模式：

- 选中文字。
- 从目录选择章节/多章。
- 从场景标题菜单选择场景。
- 从书籍详情选择全文。

### 17.2 选择模式动作

选择后先显示阅读动作：

- 高亮。
- 添加批注。
- 添加书签。
- 复制。

“发送到稿湾”作为二级动作展开：

- 去写作。
- 生成资料卡。
- 去半自动工作流。

### 17.3 转交边界

- 客户端只提交 document/revision/locator/range，不提交可伪造全文。
- 服务端重新读取权威来源并生成不可变 Envelope。
- 目标模块负责预览、确认、备份和正式写入。
- 返回 Reader 时恢复原书、原修订和来源 Locator。
- fresh/stale/missing 状态必须可见，不静默替换快照。

## 18. 数据模型扩展

### 18.1 保留

- `ReaderDocumentV2`。
- `ReaderLocatorV1`。
- Reader Document/Revision/Chapter Store。
- Reader Transfer Envelope 与目标消费服务。
- 现有分页纯核心和内容权重进度。

### 18.2 新增或升级

建议新增：

- `ReaderGlobalPreferencesV2`。
- `ReaderAppearanceProfileV1`。
- `ReaderThemeV1`。
- `ReaderFontCatalogEntryV1`。
- `ReaderAnnotationV1`。
- `ReaderLibraryViewStateV1`。
- `ReaderPositionHistoryV1`。

Reader State 升级必须是显式版本迁移；未知字段保留或安全忽略，旧全局/单书偏好自动映射为默认阅读方案。

### 18.3 偏好分层

最终有效设置按以下顺序合并：

```text
系统安全默认
  < 全局默认阅读方案
  < 用户选择的阅读方案
  < 当前书籍覆盖
  < 当前会话临时预览
```

临时预览不写盘；确认或关闭面板时按用户选择保存或放弃。

## 19. 建议磁盘布局

```text
DraftHarbor Library/
  reader-documents/
  reader-transfers/
  reader-appearance/
    profiles.json
    themes/
  reader-fonts/
    catalog.json
    <fontId>/
  reader-assets/
    paper-textures/
  reader-stats/
```

Reader Font Store、Theme Store 和 Document Store 各自唯一写入。路径只由稳定 ID 推导；前端不能传入任意落盘目标。

## 20. 错误、恢复与降级

- 字体缺失：保留方案并显示缺失状态，使用回退字体，恢复同一 Locator。
- 纹理损坏：降级为主题基础色，不阻止阅读。
- 分页失败：降级为连续模式，不覆盖用户保存的布局选择。
- 批注无法精确恢复：显示 approximate/unresolved，不静默移动到相似短句。
- 文档修订损坏：沿用 Reader Store 的可恢复旧修订策略。
- 导入失败：保留草稿和校正，不污染正式书库。
- 设置写入冲突：提示重新应用，不覆盖较新偏好。
- 转交失败：保留阅读位置、选择范围和确认界面。

## 21. 无障碍

- 正文、弱文本、焦点、选区、高亮和禁用状态分别验证对比度。
- 所有图标有可访问名称，不能只靠颜色区分状态。
- 200% 等效缩放下仍能进入所有主要设置。
- 键盘可以完成打开书库、继续阅读、翻页、目录、搜索、书签、设置和退出。
- 抽屉、对话框和工作室使用正确焦点管理与 `inert`。
- 减少动态覆盖所有页面动画、HUD 动画和纹理动态效果。
- 高亮颜色提供形状/下划线等第二识别维度。
- TTS 或屏幕阅读器始终读取连续文本顺序，双页不改变 DOM 语义顺序。

## 22. 性能预算

| 操作 | 目标 |
| --- | --- |
| 书库摘要首次显示 | 本地 500 本书 p95 < 500 ms |
| 打开已有书籍到首屏正文 | p95 < 800 ms |
| 单章读取 | p95 < 120 ms |
| 常规重分页 | p95 < 120 ms |
| 复杂字体首次加载后重分页 | p95 < 350 ms |
| 翻页输入到视觉反馈 | p95 < 50 ms |
| 搜索首批结果 | 百万字符 p95 < 1.5 s |
| 长篇常驻 DOM | 保持有界，不挂载全文 |
| 纸张纹理 | 本地资源，不能阻塞正文首屏 |

性能验收同时记录最差场景、字体、布局、视口和纹理设置，不能只记录平均值。

## 23. 视觉语言

Reader 继承稿湾品牌的沉静、文学和本地工作台气质，但阅读舞台应明显区别于写作工具页：

- 更少常驻边框和命令按钮。
- 更大的留白和稳定的正文节奏。
- 阅读控件像书签、页边和状态信息，而不是表单工具栏。
- 纸张主题使用真实材质资产和克制阴影。
- 深色主题避免大片相近灰色造成层级模糊。
- 中英文装饰标签统一语言，不再混用无信息价值的 `Reader`、`Appearance` kicker。

正式开发前必须先产出并选择视觉方向；没有被用户选中的视觉目标，不直接进入生产 UI 实现。

## 24. 验收标准

### 24.1 合格阅读器

- 用户可以从书库导入、管理、打开、继续和删除本地书籍。
- 项目作品与外部书籍使用统一阅读舞台，但来源清楚。
- 连续、单页、双页和自动布局稳定，无丢字、重复或不可达内容。
- 字体、字号、字距、行距、段距、缩进、版心和页边距可调整并恢复。
- 至少六种完整主题，纸张材质与主题覆盖整个 Reader 环境。
- 翻页输入、动画、进度、目录、搜索、书签和位置历史完整。
- 所有设置支持全局/单书作用域，影响分页时仍保持 Locator。

### 24.2 字体扩展准备

- 首期即使只有一种字体，偏好只保存稳定 `fontId`。
- 字体 Provider、目录、加载状态和缓存键均可容纳多字体。
- 测试字体缺失、加载失败、回退变化和重排恢复。
- 后续增加用户字体不修改 Reader Document、Locator 或偏好主结构。

### 24.3 稿湾联动

- 普通阅读不受转交控件干扰。
- 选区、场景、章节、多章和全文可创建不可变快照。
- 写作和工作流只读取明确 Envelope，并保留来源版本和 Locator。
- 失败、并发、过期和重复应用不破坏阅读状态或目标数据。

### 24.4 视觉与可用性

- 真实用户路径截图由人工评审，不以“无溢出”代替视觉质量判断。
- 1280×720、1366×768、1920×1080 和 100%–200% 缩放通过。
- 深色、纸张、护眼、OLED 及自定义方案通过正文和控件对比度。
- 720px 高度下正文区域不再被四层常驻 chrome 占据。
- 外观工作室可实时比较设置，不遮死正文。

## 25. 已冻结决定

- Reader 2.0 是第三核心模块，不是辅助页。
- 首先满足专业小说阅读，再提供稿湾转交。
- F-10 数据、Locator 和 Transfer 架构继续保留。
- 新导入统一进入 Reader Store，旧 localStorage 只负责迁移。
- 主题覆盖整个阅读环境。
- 首期可只开发一种字体，但必须使用可扩展字体目录与 Provider。
- 用户字体优先采用应用内安装，不要求修改操作系统。
- 页面、动画和纸张效果不得成为正文或位置的权威来源。
- 正式 UI 开发前先选择视觉方向并建立截图对照验收。

## 26. 待视觉阶段决定

- 书库首页采用封面墙、混合仪表盘还是更偏实体书架的视觉方向。
- HUD 默认隐藏时间和边缘触发方式。
- 页面圆角、阴影、书脊和纸张材质的最终强度。
- 默认主题、默认版心和默认状态栏字段。
- 快捷外观条的位置与交互形式。
- 高亮和批注工具条的视觉语言。

这些属于视觉与交互参数，不影响本文件冻结的数据和模块边界。
