### F-06 产品边界

- 它是单次执行的资料库维护器，不建设通用 Agent、长期记忆、工具注册、多 Agent、向量数据库、后台定时任务或自主循环。
- 模型不接触文件路径和文件系统，只接收程序提供的当前项目资料卡快照，并返回结构化 JSON 建议。
- 第一版只提供：资料库体检、整理建议、预览差异、应用选中补丁。
- 第一版允许建议修改 `summary`、`tags`、`aliases`、`characterProfile`；禁止修改 `id`、`projectId`、`type`、`category`、`title`、`body`、`sourceReferences`、时间戳和排序字段。
- 第一版不允许删除、合并或创建资料卡；可以报告疑似重复，并给出人工处理建议。
- 小说场景和章节正文不可读、不可写；资料卡 `body` 仅作为分析上下文读取，是否开放修改留到 F-06 完成后的独立决策。
- Agent 使用专门选择的 Provider 配置组；不得隐式继承当前写作模型。API Key 不进入 Prompt、任务历史、日志或补丁数据。
- 所有模型输出都是建议，必须经过 JSON 解析、字段白名单、目标卡存在性、版本一致性和数量上限校验。

## 统一规则

- AI 结果一律先进入预览态，不得直接覆盖正文或正式资料。
- 所有写入动作必须由用户确认，并复用现有备份与恢复机制。
