# 稿湾 DraftHarbor 1.2.1

`v1.2.1` 是基于 v1.2.0 的写作体验与稳定性补丁版。它保留资料库管家、沉浸阅读器和半自动小说工作流，并合入此前独立开发分支中的写作增强。

## 主要更新

- 场景正文变化后自动标记场景与章节摘要过期，避免旧摘要继续进入 AI 上下文。
- 章节摘要输入增加长度预算，并提供摘要模板选择、前台查看与右键入口。
- Provider 更严格地区分推理过程与最终正文，避免 Thinking 内容写入摘要或正文。
- 新增全局写作前缀，可在设置页或写作页直接维护，并作为 AI 请求的首条 system 指令发送。
- 写作区左右侧栏支持拖拽调整；右侧功能标签在窄栏下自动换行。
- 修复配置检查因 API Key 不回显而产生的误报。
- 新项目默认章节与场景名称统一为中文，并兼容显示历史系统默认英文标题。

## 验证

- 完整自动化测试：`npm test`
- 写作功能与布局审计
- 阅读模块结构与布局审计
- 工作流发布验收，包括百万字符项目和 500 条事件
- Windows NSIS 与 Portable 构建
- 打包程序启动与核心 API 冒烟测试
