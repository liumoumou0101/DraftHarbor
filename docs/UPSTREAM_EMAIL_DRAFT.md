# 给 Writingway 2 作者的邮件草稿

Subject: Thank you, and a quick license confirmation for Writingway 2

Hi,

Thank you for creating and publishing Writingway 2.

I originally forked the project because I wanted better support for newer DeepSeek models and Chinese long-form writing workflows. What began as a small personal modification gradually became a much larger rewrite. The new application now uses an Electron desktop architecture, a separate local storage and service layer, a redesigned interface and data model, and an independent test and release system.

I have separated the desktop application into a new project named DraftHarbor (稿湾). It has a new repository history, product name, application identifier, protocol and visual identity. The old web fork remains separate. The new project's README and NOTICE clearly acknowledge Writingway 2 as its starting inspiration and state that DraftHarbor is not an official version or endorsed branch.

I noticed that the Writingway 2 README says the project is released under the MIT License, but the repository does not currently contain a LICENSE file. Could you please confirm that the Writingway 2 code is intended to be available under the MIT License?

Only a short confirmation is needed. I do not expect you to support or review the new project.

Thank you again for making Writingway 2 available and for the ideas that helped start this work.

Best regards,

[Your name or GitHub username]
