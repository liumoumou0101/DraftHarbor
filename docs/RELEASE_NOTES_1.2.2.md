# 稿湾 DraftHarbor 1.2.2

`v1.2.2` 是阅读体验增强与稳定性补丁版，重点更新 Reader 2.0、真实翻页和带图阅读模式。

## 主要更新

- 重构阅读书库、分页、目录、搜索、书签、批注、字体、朗读和阅读外观能力。
- 引入稳定的双向真实翻页效果，修复字体缩放、透明动画、书脊遮挡、段首缩进和页面闪动问题。
- 默认使用双页阅读，并保留单页、连续、自动和带图模式。
- 新增带图阅读：左侧正文、右侧图片；每页可独立设置图片，支持点击选择或拖入，翻页后按触发位置切换。
- 配图保存在本地 Reader 书库，不修改来源图片；支持 PNG、JPEG、GIF 和 WebP。
- 专注阅读改为只读状态，禁止添加、拖入或移除图片，并阻止批注、高亮、下划线和书签写入。

## 验证

- Reader 核心、存储、协议、翻页和桌面阅读自动化测试。
- 同一章节多页不同图片、左右翻页恢复和图片持久化验证。
- 专注阅读图片及文字标记只读回归。
- Windows NSIS 安装版、Portable 便携版构建与打包冒烟测试。

升级前建议备份重要项目。现有项目、Reader 书库和旧版导入格式继续兼容。
