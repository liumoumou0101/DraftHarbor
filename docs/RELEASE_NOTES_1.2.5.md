# 稿湾 DraftHarbor 1.2.5

## 本次更新

- 阅读器分页改为按实际稿纸、字体、字号、行距、页边距和窗口尺寸测量，不再依赖平均字数估算，页面能够更充分地铺满。
- 分页断点保护自然标点、空白、Unicode 字素以及孤行寡行，避免末行只占一半、组合字符被拆开或下一个字过早跳到下一页。
- 淡入、滑动和覆盖翻页改为双缓冲快照交接，消除新页先闪现一帧和动画结束时替换正文造成的文字闪烁。
- 双页模式的滑动与覆盖只在左右固定页槽内运动，书脊和中央装订间隙保持不动。
- 收紧翻页会话清理与溢出检测，快速连续翻页、切换设置和重新分页不会遗留动画层或残影。
- 修复高缩放、低窗口高度下阅读器外层被导航栏撑开并整体滚动的问题；分页和 HUD 布局审计会等待缩放重排稳定后取样。
- 阅读器成熟核心文件预算放宽到 32 KiB，同时继续保留 1400 行全局单文件门禁和独立子模块预算。
- 修正 Electron Builder 的本地发布配置，构建阶段明确禁止提前上传，同时不再把 `never` 误识别为发布 Provider。

## 验证

- `npm run lint`、`npm run smoke`、`npm run unit`，桌面主线 UI 用例逐项通过。
- `npm run reader-quality-acceptance`：逐帧动画、百万字符性能、12 路发布矩阵、多视口布局、真实视觉与无障碍验收全部通过。
- Windows x64 NSIS 安装版与 Portable 便携版构建。
- unpacked 应用完成项目创建、保存、重开和备份冒烟。
- NSIS 完成静默安装、启动、持久化、备份与卸载冒烟。
- Portable 在隔离数据目录完成启动与主窗口响应检查。
