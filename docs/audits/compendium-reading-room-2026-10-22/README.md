# 资料库 · 私人书房改版验收

2026-10-22。基于当前工作区实现，保留前一轮资料完整性修复；使用独立的虚构《无渡》样例进行验证。

## 已实现

| 体验 | 实际行为 |
| --- | --- |
| 阅读式资料页 | 默认目录＋阅读页；标题、简介、正文与人物侧写原地编辑，长文本自动展开；空人物字段可按需补充 |
| 目录 | 按类型分组、关键词搜索、类型筛选、名称／最近修改排序、项目内收藏；记住资料选中项和阅读位置 |
| 外观 | 暖纸色与墨色；独立外观偏好；窄窗口可收起目录 |
| 关联与来源 | 区分正文提及、明确场景关联、场景人物、条目文字提及、共同标签和历史来源摘录；不把推测关系当作作者声明 |
| 场景联动 | 来源存在时可跳转真实写作场景，经过原有未保存离开保护；不存在的场景不提供错误跳转 |
| 写作速览 | 写作参考列表及人物条目可打开资料速览；保留正文、光标选区、滚动及继续输入后的焦点；支持真实手动引用 |
| 编辑保护 | 显式保存、Ctrl/Cmd+S、失败保留草稿、版本冲突检查、写入中保护；放弃修改需要确认 |
| 操作反馈 | 目录悬停、按钮轻压、辅助面板短距离展开、速览淡入；支持减少动态效果；键盘操作避开输入和中文组合输入 |

现有抽卡、AI 改写、体检、问答、阅读提取、工作流转存入口继续可达。没有迁移用户资料格式或引入新运行时依赖。

## 回归证据

`npm run compendium-experience-test` 整合通过 87 项：

- 编辑安全 14、资料管家 UI 16、AI 弹窗 22。
- 新增关联分析 12、工作区 16、写作速览 7。

额外定向验证：上下文回归 11、转存安全 13、关闭保护 11、写作项目切换 7、写作保存状态 4、写作上下文一致性 5、写作推理状态 12 项通过。写作交互 25 项由独立任务验证通过。

全仓库 `npm run lint`、`git diff --check` 通过。浏览器测试使用本机已安装 Chrome，临时资料目录隔离；没有付费模型调用。

视觉验收 9 组、14 张截图，详见 [visual-acceptance.json](visual-acceptance.json)。包括 1024／1280／1440／1920 窗口、明暗模式、长标题与正文的完整保存、500 条目录、减少动态效果、实际写作引用状态及无项目状态。没有页面错误或 HTTP 请求。抽样检查的辅助文字最低对比度为纸色 4.68:1、墨色 4.89:1；此项不代表完整无障碍认证。

独立复审发现并修复了实际项目加载器未恢复选中项、媒体查询覆盖目录收起规则、辅助文字对比度不足等问题；修复后已复核。实际 DOM 验证还覆盖了隐藏页面加载后的文本高度、空目录恢复、主题按钮选择器、菜单关闭与焦点恢复。

## 边界

- 正文提及与相关资料通过现有文字和元数据计算，不代表人工维护的关系图。
- 来源按钮打开对应场景，尚未做精确历史摘录段落定位。
- AI 相关验证使用受控提供商；未调用真实模型。
- 完整 HTTP 集成曾受当前环境 localhost 权限限制，本次结果不能等同于完整 `npm test` 或全部模块端到端验收。
- 桌面预览构建成功，271 个源码／资源文件与 app.asar 一致；原发行目录未变。自动启动测试在 Electron 进程创建阶段失败，尚未通过真实桌面端到端验证。详情见 [PACKAGING.md](PACKAGING.md) 和 [package-verification.json](package-verification.json)。此处记录提交前的验收状态；预览未作为正式版本发布。
