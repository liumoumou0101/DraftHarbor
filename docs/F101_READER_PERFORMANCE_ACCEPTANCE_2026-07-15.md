# F-10.1 Reader 数据基础性能验收

- 日期：2026-07-15
- 环境：Windows 11 家庭版（中文版），AMD Ryzen 5 7535H，15.2 GiB RAM，本地临时目录
- 运行时：Node v24.11.1，Electron 42.4.1，win32-x64
- 命令：`npm run reader-performance-acceptance`

## 夹具与方法

使用代码确定性生成的 `reader-million-balanced` Markdown：1,000,311 个 UTF-16 字符、100 章、1,000 个正文块，不含真实书稿。先预热 1 次，再测量 5 次；报告中位数和 p95。每次均执行文件读取与解析预览、源文件复制与不可变 Revision 提交，并从磁盘随机读取第 50 章。测试结束删除临时书库和源文件。

## 结果

| 操作 | 中位数 | p95 | 预算 | 结果 |
| --- | ---: | ---: | ---: | --- |
| 百万字符解析并形成预览 | 25.78 ms | 29.34 ms | p95 ≤ 8,000 ms | 通过 |
| 确认入库并原子提交 | 338.99 ms | 361.92 ms | p95 ≤ 7,000 ms | 通过 |
| 单章按需读取 | 1.16 ms | 1.47 ms | p95 ≤ 1,200 ms | 通过 |

测试过程中观测到的 Node 堆增长峰值为 23.45 MiB，低于 300 MiB 硬上限。书库索引、文档元数据和 Revision 元数据均验证不含正文标记；正文只存在于按章文件和 Revision 级源副本。

## 适用范围

本次只验收 F-10.1 核心与 Store 数据路径。首屏渲染、DOM 数量、分页、相邻页翻页、搜索和 UI 堆增量需在 F-10.2/F-10.3 对发布 Electron 界面继续测量，不能用本结果替代。
